# Skill Card: anti-slop-review

## Description
Reviews implemented UI and public prose through hard defects, coherence problems, template risks, and AI-writing tells without turning aesthetic or voice preferences into universal bans.

## Owner
ABVX / Anton Biletskiy-Volokh

## License
MIT. See repository LICENSE.

## Intended Use
Use for bounded pre-ship screenshot, browser, code, README, guide, launch-note, or public-copy review of landing pages, product surfaces, dashboards, docs pages, and redesigns.

## Out of Scope
Not a replacement for a product brief, design system, accessibility audit, browser test suite, brand strategy, source audit, legal review, or frontend implementation skill.

## Sources and Attribution
Adapted from a user-supplied anti-slop design law. No author, source, or redistribution license was supplied, so the original text is retained only in the user's local installation and is not distributed here.

## Inputs and Outputs
Inputs: brief, design-system constraints, screenshots/live UI, viewport and interaction evidence, voice samples, source boundaries, and relevant files.

Outputs: at most seven stable findings, bounded corrections, `detect`-mode prose audits, `edit`-mode prose rewrites with post-edit self-check, verification steps, and a scoped ship verdict.

## Risks and Mitigations
- Risk: subjective taste blocks shipping. Mitigation: only reproduced hard defects block; style findings require contract evidence.
- Risk: marketing taste applied to utility UI. Mitigation: establish surface register and primary task first.
- Risk: checklist design. Mitigation: template patterns are scrutiny prompts, not bans.
- Risk: context bloat. Mitigation: compact core plus on-demand references.
- Risk: broad redesign. Mitigation: smallest coherent correction and explicit authority boundary.
- Risk: humanization invents facts or hides AI origin. Mitigation: no-fabrication rule, source-boundary check, and framing as truthful prose QA rather than detector evasion.

## Evaluation
Scenario review should distinguish a real visibility/contrast/control/prose-trust defect from an intentional pill, gradient, familiar layout, utility-first design choice, or legitimate author voice.
