# Skill Card: editorial-surface

## Description
Improves text-first public surfaces by tightening hierarchy, excerpt logic, body readability, and media rhythm across articles, guides, book sections, and content indexes.

## Owner
ABVX / Anton Biletskiy-Volokh

## License
MIT. See repository LICENSE.

## Intended Use
Use for longform pages and content listings where the main success criterion is readable, intentional editorial structure rather than generic marketing polish.

## Out of Scope
Do not use for dense dashboards, utility-first settings pages, or copy rewrites when the content body is already owner-approved and only layout needs correction.

## Sources and Attribution
ABVX adapted from bergside `awesome-design-skills` editorial pattern library, narrowed around reusable hierarchy and reading-rhythm corrections rather than broad style generation: https://github.com/bergside/awesome-design-skills

## Inputs and Outputs
Inputs: page role, existing layout, approved content, screenshots, CSS/components, and any design context.

Outputs: hierarchy corrections, excerpt rules, media-placement rules, and desktop/mobile reading checks.

## Risks and Mitigations
- Risk: over-polished layout that weakens reading. Mitigation: prioritize measure, hierarchy, and rhythm over decoration.
- Risk: rewriting content to hide layout weakness. Mitigation: preserve owner-approved body unless the task explicitly asks for copy edits.
- Risk: dead-space fixes that make cards bloated. Mitigation: add only enough excerpt or structure to match the card role.

## Evaluation
Evaluated by structural validation and ABVX-style editorial surface review criteria.
