# Skill Card: wireframe-preflight

## Description
Runs a cheap low-fidelity wireframe pass before frontend implementation so layout, hierarchy, and flow problems are caught before expensive code and polish loops begin.

## Owner
ABVX / Anton Biletskiy-Volokh

## License
MIT. See repository LICENSE.

## Intended Use
Use for landing pages, editorial surfaces, partner-facing sections, hero redesigns, and other frontend work where structure is still uncertain.

## Out of Scope
Do not use for final visual polish, accepted-layout bug fixes, or dense product UIs whose main problem is workflow research rather than page structure.

## Sources and Attribution
ABVX adapted from agilek `wireframer-skill` low-fidelity prototype concept, constrained for small, reviewable pre-implementation passes: https://github.com/agilek/wireframer-skill

## Inputs and Outputs
Inputs: brief, required sections, approved copy, supplied assets, screenshots, and owner constraints.

Outputs: one primary wireframe direction, optional fallback direction, desktop/mobile structure, structural risk callout, and bounded implementation notes.

## Risks and Mitigations
- Risk: turning wireframing into another exploration sink. Mitigation: cap the pass at one primary approach and one meaningful fallback.
- Risk: fake certainty from pretty mockups. Mitigation: keep the output low fidelity and structural.
- Risk: scope drift into copywriting or product invention. Mitigation: preserve approved content and task boundaries.

## Evaluation
Evaluated by structural validation and intended-use review for pre-implementation frontend tasks.
